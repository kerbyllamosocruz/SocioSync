# BeeTok Automation Helper - Chrome Extension

Automates SocialBee profile connections, caption variations, and fast cross-tab TikTok OTP synchronization.

---

## 🚀 Quick Installation Guide (Chrome / Edge / Brave / Opera / Dolphin{anty})

### Option A: Load Unpacked in Dolphin{anty} Profile (Recommended)
1. Open **Dolphin{anty}** -> Edit your browser profile.
2. Under **Arguments** / **Command-line args**, add:
   ```text
   --load-extension="C:\Users\Ken\Documents\Kerby\work\automation\extension"
   ```
3. Click **Save** and start your profile.

---

### Option B: Install via Chrome Developer Mode
1. Open your browser's extension page:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
   - **Brave**: `brave://extensions`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked** and select the `extension` folder inside this repository.

---

## 🔄 How to Update the Extension

- Run `git pull` inside the repo directory (or update files), then click the **Reload** (🔄) icon on the extension card in `chrome://extensions`.

---

## ✨ Features & Capabilities

- ⚡ **Instant Navigation**: Auto-clicks *"Use phone / email / username"* menu options without delay.
- 🔑 **Cross-Tab OTP Synchronization**: Auto-receives and fills TikTok 6-digit OTP codes from `m.kuku.lu` in real-time.
- 🐝 **SocialBee Integration**: Automates multi-account profile connections, caption variations, and image batch uploads.
