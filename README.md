# SocialBee & TikTok Automation Suite - Chrome Extension

An all-in-one browser extension for SocialBee caption filling, image management, TikTok login navigation, CAPTCHA auto-solving, and cross-tab OTP verification via `kuku.lu`.

---

## 🚀 Quick Installation Guide (Chrome / Edge / Brave / Opera)

### Option A: Install via Git Clone (Recommended for easy updates)
1. Open your terminal / command prompt and clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   ```
2. Open your browser's extension page:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
   - **Brave**: `brave://extensions`
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** and select the `extension` folder inside this repository.

---

### Option B: Install via ZIP Download
1. Click the green **Code** button at the top of this GitHub repository and select **Download ZIP**.
2. Extract the downloaded ZIP file to a folder on your computer.
3. Open `chrome://extensions` (or your browser's extension page).
4. Enable **Developer mode** (toggle in top-right).
5. Click **Load unpacked** and select the extracted `extension` folder.

---

## 🔄 How to Update the Extension

- **If installed via Git**: Run `git pull` inside the repo directory, then click the **Reload** (🔄) icon on the extension card in `chrome://extensions`.
- **If installed via ZIP**: Download the latest ZIP, replace the folder contents, and click the **Reload** (🔄) icon in `chrome://extensions`.

---

## ✨ Features & Capabilities

- ⚡ **Instant Navigation**: Auto-clicks *"Use phone / email / username"* menu options without delay.
- 🔑 **Cross-Tab OTP Synchronization**: Auto-receives and fills TikTok 6-digit OTP codes from `m.kuku.lu` in real-time.
- 🧩 **TikTok CAPTCHA Solver**: Integrates with SadCaptcha for automated puzzle slider and rotation CAPTCHA solving.
- 🐝 **SocialBee Integration**: Automates multi-account profile connections, caption variations, and image batch uploads.
